Method: GitHub code search for `github.com/HdrHistogram/hdrhistogram-go` and for the pre-transfer path `github.com/codahale/hdrhistogram` in `go.mod` files
(100 results per query, the search limit), each hit's `go.mod` fetched to tell **direct** from `// indirect` and to read the pinned version, forks and archived
repositories dropped. This undercounts: it misses repositories beyond the first 100 hits, vendored copies, private code, and projects that use the library
only through `go.sum`. For the full importer count see the "Imported by" tab on pkg.go.dev, which was not fetched here.

still resolves to the same lineage; those projects have not moved to the `HdrHistogram` module and do not receive v1.x releases).
